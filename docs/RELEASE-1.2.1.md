# Velora 1.2.1

English and Arabic interface with saved language choice, correct RTL layout, bundled Arabic fonts, and a cleaner brand header.

PDF to Word (.docx) exports editable text with basic styling and page breaks. Scanned pages remain images; no OCR. DOCX to PDF now works without Office using a basic local renderer with rasterized PDF pages. LibreOffice is still preferred when installed for richer formatting and selectable text. Complex layouts, headers, footers and floating shapes may change.

Optional Support opens https://tip.dokan.sa/solitary. Original files, global shortcuts, tray behavior, image/media conversion and the drag wheel are retained.

Extract the entire ZIP and open Velora.exe. Do not mix runtime files from older versions. The Windows workflow validates the actual bundled Python, Qt and conversion engines before uploading this release.

Both Latin and Arabic fonts are bundled so the interface does not depend on installed system fonts.
